# ✍️ CNN Handwritten Digit Recognition

A beginner-friendly **PyTorch CNN project** covering MNIST preprocessing, model building, training, evaluation, and interactive handwritten digit recognition (0–9).

## 📚 Topics

### 1. 📂 Load MNIST Dataset

Learn how to load and visualize handwritten digit images (0–9).

### 2. 🖼️ Preprocess MNIST Images

Learn how to convert images into tensors, normalize pixel values, and organize images into batches.

### 3. 🧠 Build a CNN Model

Learn how to build a CNN using Convolution, ReLU, Pooling, Flatten, and Fully Connected Layers.

### 4. 🔄 Forward Propagation

Learn how images pass through CNN layers to produce classification scores.

### 5. 🏋️ Train CNN Model

Learn how to train a CNN using Cross-Entropy Loss, Adam Optimizer, and Backpropagation.

### 6. 📊 Evaluate CNN Model

Learn how to evaluate a trained CNN using MNIST test images and calculate accuracy.

### 7. 🔍 Make Predictions

Learn how to predict handwritten digits and compare predicted labels with actual labels.

### 8. ✍️ Draw and Predict Digits

Learn how to draw handwritten digits using Tkinter and recognize them with a trained CNN.

## 🔄 CNN Workflow

```text
MNIST Dataset
     ↓
Image Preprocessing
     ↓
Build CNN Model
     ↓
Forward Propagation
     ↓
Train CNN Model
     ↓
Evaluate CNN Model
     ↓
Make Predictions
     ↓
Interactive Handwritten Digit Recognition
```

**Note:** The trained model (`cnn_mnist.pth`) is generated by running `05_train_cnn.py` and is required for evaluation and prediction.
